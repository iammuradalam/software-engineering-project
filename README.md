# Software Engineering Course Project

## Background

Lasers and Feelings is a quick-play role-playing game set in space. Players are part of the crew of an interstellar scout ship and take part in adventures involving exploration, aliens and different space-related dangers.

## Introduction

The purpose of this project is to develop software that supports players and the GM during a Lasers and Feelings game session. The software should make important game activities easier, especially dice throwing. It can also support character information and other information needed during the game.

## Dictionary

- **GM:** The person who manages and leads the game session.
- **Player:** A person who takes part in the game.
- **Dice throw:** A random result between 1 and 6.
- **Character:** The role controlled by a player during the game.
- **Character number:** A number used by the player when comparing game actions with dice results.
- **Style:** Information describing the character's personality or appearance.
- **Role:** The character's main role in the game.

## Requirements

### Product backlog

1. As a player, I want to be able to set my number, so I can compare it with the result of my dice throw.
2. As a player, I want to be able to give my character a name, because I want to be immersed into the game.
3. As a player, I want to be able to choose a style and role for my character, so I can remember them.
4. As a player, I want the software to save my information (number, name, style and role), so I can use them in multiple playing sessions.
5. As a GM, I want to be able to throw a dice, so I can create a random adventure.
6. As a player, I want to view my saved character information, so that I can check my character details during the game.
7. As a player, I want to see my latest dice result, so that I can remember the outcome of my most recent action.
8. As a GM, I want to view the players' character information, so that I can manage the game session more easily.
9. As a GM, I want to generate a random adventure idea, so that I can quickly create events for the players.

### Sprint 1 backlog

- (In progress) As a GM, I want to be able to use the software in a modern web browser, because they are easy to use and easily available.
- (Not started) As a player, I want to be able to throw a dice, because the result of the throw determines if I succeed or not in whatever I am trying to do.
